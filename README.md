CampusClaw
面向高校班级的课程材料管理平台，提供统一的课程资料存储与管理能力，并通过角色权限和班级隔离保证数据安全。

教师和学生登录后进入所属班级空间，教师可以上传课程材料并完成入库，学生可以查看本班材料；系统提供预置样本数据，并支持 Docker Compose 一键启动和 /health 健康检查。

系统支持严格按登录班级隔离的课程知识库问答：PDF、纯文本和 Markdown 会建立关键词索引，并可通过服务端配置的私有或明确批准的 OpenAI-compatible 嵌入/生成服务进行向量、关键词或默认混合（RRF）检索。回答只使用本次单轮请求的授权证据，事实陈述带可核验引用；证据不足时返回 `根据本班资料无法回答该问题`。不支持 OCR，其他格式仍可下载但不可检索。

模型端点、密钥、Qdrant 地址、数据边界、模型、维度和限额仅存在于后端；问题和资料正文按最小范围发送，未经批准不得外发。PostgreSQL 保存正文和来源，Qdrant 仅保存同 ID 向量及必要标识，向量丢失可重建。系统仍不实现多轮聊天、自主 Agent/工具调用、作业提交、学情诊断、教案/命题生成、注册、找回密码、技能/MCP、多智能体或知识图谱。

运维启动、生产配置、备份恢复和学期范围说明见 [`docs/operations.md`](docs/operations.md)。
