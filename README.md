CampusClaw
面向高校班级的课程材料管理平台，提供统一的课程资料存储与管理能力，并通过角色权限和班级隔离保证数据安全。

教师和学生登录后进入所属班级空间，教师可以上传课程材料并完成入库，学生可以查看本班材料；系统提供预置样本数据，并支持 Docker Compose 一键启动和 /health 健康检查。

系统支持严格按登录班级隔离的课程知识库问答：PDF、纯文本和 Markdown 会建立关键词索引，并可通过服务端配置的私有或明确批准的 OpenAI-compatible 嵌入/生成服务进行向量、关键词或默认混合（RRF）检索。回答只使用本次单轮请求的授权证据，事实陈述带可核验引用；证据不足时返回 `根据本班资料无法回答该问题`。不支持 OCR，其他格式仍可下载但不可检索。

教师可创建多个本班智能体和 `solution_guidance` 技能，仅创建者可管理私有配置、绑定、发布及退休。学生可选择本班已发布智能体进行持久化多轮引导式聊天；每轮加载最新有效配置与有界服务端历史，重新检索、授权并校验本轮证据，历史不是事实依据。旧 `POST /api/knowledge/query` 保持单轮、非流式和原契约。

消息通过 Bearer 认证的 fetch/SSE 交付：完整模型输出先缓冲验证，再发送文本增量和引用，不透传原始模型 token。学生删除会话为软删除，智能体创建教师仍可审计保留内容；其他教师不可查看。保留期由部署政策确定，没有自动清除任务。

模型端点、密钥、Qdrant 地址、数据边界、模型、维度和限额仅存在于后端；问题、配置、历史和资料正文按最小范围发送，未经批准不得外发。PostgreSQL 保存正文、来源、不可变配置修订和会话，Qdrant 仅保存同 ID 向量及必要标识，向量丢失可重建。所有受保护 API 保持 Bearer 身份认证和服务端班级隔离。

同源 Swagger UI：`/api/docs`；OpenAPI：`/api/openapi.json`。文档公开，受保护接口试调仍须 Bearer token，API/数据库不直接映射主机端口。隔离、确定性替身与只读数据库断言的黑盒验收见 [`apitest/README.md`](apitest/README.md)，不使用开发数据库或真实模型。

当前非目标：自主规划、模型工具调用、MCP、智能体间协作、知识图谱、作业提交、学情诊断、教案/命题生成、注册与找回密码。支持多个独立教师配置的智能体不意味着支持多智能体协作。

运维启动、生产配置、备份恢复和学期范围说明见 [`docs/operations.md`](docs/operations.md)。
