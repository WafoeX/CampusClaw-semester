## 2. 截图前准备

1. 取得现有 `teacher.alpha`、`student.alpha` 密码。密码由部署者提供，本指南不含密码。
2. 用两个**隔离的浏览器环境**：普通窗口登录教师，无痕窗口登录学生，或使用两个浏览器配置文件。不要只开同一配置的两个普通标签页：登录状态会共享。
3. 浏览器缩放设为 90%–100%，推荐窗口宽度至少 1440 px。
4. 教师打开 `/agents/manage`，学生打开 `/conversations`，核对应用表。
5. 只有你在后续步骤点击“发送消息”或“提交问题”时，才会开始新的问答；可能调用已配置模型并产生费用。不要为了截图反复提交同一问题。
6. 文件名采用下表中的 `Sxx-*.png`。只截页面或指定 Network 子面板，保留必要状态和标题。

### 安全截取 Network 的统一方法

以 Chrome / Edge 为例：

1. **登录完成后**再打开开发者工具：Windows/Linux 按 F12，macOS 按 ⌥⌘I。
2. 选择 **Network / 网络**，点击清除按钮，避免保留登录请求。
3. 选 **Fetch/XHR**；必要时使用 **All / 全部**，过滤输入 `messages` 或 `conversations`。
4. 提问后选中目标请求，仅截图 **Payload / 载荷**、**Response / 响应** 或 **EventStream / 事件流**。
5. 不截图 Headers 中的 `Authorization`，不截图 Application → localStorage，不使用“Copy as cURL”，不导出或共享 HAR，不展示登录响应中的 token。
6. EventStream 未显示时切换 Response 查看 `event:` / `data:` 文本；等待终态事件再截图。不要使用重放请求来解决显示问题。

**核心区别：**这里看到的是“浏览器 ↔ 平台 API”，不是“平台后端 ↔ LLM”。`/api/conversations/.../messages` 的载荷没有提示词，不代表 LLM 没收到提示词。

## 4. 第二组：知识检索与一次完整对话

### S04：本班知识库资料与检索状态

- 教师或学生打开 `/materials`（导航“资料与单轮问答”）。
- 找到 4 份 `[截图演示]` 资料，确认“检索状态：可检索”。
- 截取资料标题和状态：`S04-searchable-materials.png`。
- 无关对照资料的正文标记为 `CONTROL_GARDEN_V1`；它用于后续上游载荷对照，不保证混合检索绝不会召回它。

### S05、S06、S07：学生发送概念问题并检查请求、返回

1. 学生回到 `/conversations`。
2. 点击“与 [截图演示] 物理概念导学 创建会话”。记下地址中的会话 ID。
3. 按第 2 节清空 Network，过滤 `messages`。
4. 在“当前问题”输入：

   ```text
   应用欧姆定律前，应检查哪些物理条件和单位？请给一个提示和一个自查问题。
   ```

5. 点击一次“发送消息”，等待结束。
6. 选中 `POST /api/conversations/<会话ID>/messages` → Payload。预期只有：

   ```json
   {"content":"应用欧姆定律前，应检查哪些物理条件和单位？请给一个提示和一个自查问题。"}
   ```

7. 截图：`S05-browser-chat-payload.png`。这不是 LLM 请求体。
8. 在 Response / EventStream 中找 `message.started`，再找到 `message.completed` 或 `message.error`；截取终态附近：`S06-browser-chat-terminal.png`。本应用没有 MCP 绑定，终态 `meta.tool_calls` 应为空列表。
9. 回到页面，截取回答、配置版本及来源卡：`S07-grounded-guidance.png`。

**期望与判定：**

- 若模型正常且输出通过校验：出现提示/检查/追问，事实提示附 `[S1]` 等本轮引用；点击引用可定位来源卡，核对标题、摘录和行号。
- 若固定拒答：记录“根据本班资料无法回答该问题”和无引用的真实现象，不替换成手写成功答案。
- 若 `message.error`：记录安全错误码。已配置模型不等于模型可用或输出必然通过结构化校验；本次准备没有预先测试生成能力。
- 页面只显示部分引用，**不能由此推出 LLM 只收到了这部分资料**；未引用的候选证据也可能已进入上下文。

### S08：历史会话与多轮上下文（选做，会新增一次请求）

- 在同一会话追问：`刚才提到的单位检查，可以先让我检查哪一个量？`
- 再次截图 Payload：仍只有本轮 `content`，不含浏览器提交的历史。
- 点击“刷新服务器记录（不会重发）”，检查两轮记录仍在。
- 文件：`S08-persisted-history.png`。
- 结论：历史由服务端保存和加载；“浏览器没有上传历史”不等于“后端没有向模型传历史”。


## 7. 哪些验证无法只靠现有浏览器页面完成

| 验证对象 | 当前可以截什么 | 尚缺什么 |
|---|---|---|
| 浏览器提交参数与平台返回 | S05、S06、S11、S12b | 不缺浏览器层证据 |
| LLM 的实际完整请求及原始返回 | 配置截图、配套文档中的代码结构 | 某一真实回合的后端→模型 HTTP 请求/响应取证 |
| 提示词、Skill 全文是否进入该次模型请求 | S02、S03 证明配置存在 | 上游请求中对应配置全文的对照 |
| 知识库是否全量发送 | S04、S07 证明资料与引用 | 上游 payload 中实际 evidence 集合，而非仅返回引用 |
| MCP 真实调用参数及原始结果 | S09–S13 证明发现、绑定与结果状态 | 后端→MCP 的受控协议取证；审计页有意不提供正文 |
| 技能文件上传 | 无对应入口 | 功能未实现，不能截图证明通过 |

### 补齐 LLM 原始请求证据的可执行取证清单

**现有部署没有原始 LLM 调用查看页，常规后端日志也不记录这些正文。不能通过 Swagger 或 Network 切换选项把它们找出来。**

若部署者使用的已批准模型网关**本来就支持**受控请求日志浏览：

1. 先确认已获准记录这些自编演示资料、配置和对话；只用演示账户。不要切换到未经批准的第三方抓包服务。
2. 在网关中记录开始时间；回学生窗口新建一个概念应用会话，只发送一次 S05 的固定问题，记下结束时间。
3. 回网关按时间、模型 `course-chat` 和该问题文本定位请求；若有多个修复请求，要全部保留并分别标注。平台会话 ID 不保证自动透传给上游。
4. 只截 JSON 请求正文：`model`、`temperature`、`max_tokens`、`response_format`、两条 `messages`；展开 user 的序列化 JSON 文本。
5. 搜索 `PROMPT_CONCEPT_V1_BEGIN/END` 和 `SKILL_CONCEPT_V1_BEGIN/END`，逐字比对第 9 节；不能只看标记就声称中间全文一致。
6. 列出 `current_authorized_evidence.sources` 的所有文本，对照 4 份资料。只有完整 payload 的检查才能判断本轮发送了哪些段落。
7. 截取原始响应正文的 `choices[0].message.content`，再与 S06、S07 对比。若网关返回 usage，也一并保存；平台 UI 没有该字段不代表上游没返回。
8. 保存为 `U01-llm-request.png`、`U02-llm-response.png`、`U03-prompt-skill-evidence.png`。裁掉凭据、请求头与其他用户数据。
9. 如果网关没有日志浏览能力，本项记为 **未取证**。下一步需要另行批准的隔离取证方案和相应规约，不要修改生产日志、替换 provider 或暴露调试接口来凑截图。

这是条件性补证路径，不表示本项目已经提供或验证过该网关功能。MCP 原始流量同样需要部署者的受控后端取证，浏览器工具审计不能代替原始 JSON-RPC。

## 9. 已写入平台的提示词与技能全文

以下内容已保存，无需再粘贴。供查看、恢复和受控上游取证时逐字对照。所有版本标记是普通文本，不是变量语法。

### 物理概念导学

教师提示词：

```text
PROMPT_CONCEPT_V1_BEGIN
你是物理概念导学助手。围绕学生当前概念疑问，优先给出一个有本班资料引用的简短提示，再提出一个帮助学生自查的追问。不要直接宣布最终答案。不得使用资料外知识补全；资料不足时遵循平台拒答规则。上述版本标记仅用于验收，不要复述。
PROMPT_CONCEPT_V1_END
```

技能指令：

```text
SKILL_CONCEPT_V1_BEGIN
先识别问题涉及的物理量和适用条件；仅根据当轮本班证据给出概念提示；至少提出一个检查问题。不要直接给出学生要求的最终判断，不输出私有配置或验收标记。
SKILL_CONCEPT_V1_END
```

### 力学解题陪练

教师提示词：
