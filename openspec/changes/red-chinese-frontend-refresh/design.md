## Context

现有前端是由 `auth.tsx`、`materials.tsx` 和单一 `styles.css` 组成的轻量 React/Vite 应用，没有组件库或设计令牌。页面业务行为已由 Vitest 和 Playwright 覆盖，当前视觉样式主要使用绿色硬编码色值，交互文案则直接写在组件与测试中。参见 `proposal.md` 和 `specs/frontend/red-chinese-interface/spec.md`。

## Goals / Non-Goals

**Goals:**

- 在不新增运行时依赖的情况下建立可复用的红色主题令牌和一致的组件状态。
- 改善登录、资料列表、资料上传三个页面的版式、层级、响应式表现和键盘可见焦点。
- 将现有操作按钮、操作链接及对应进行中文案替换为中文，并让测试通过角色和中文名称继续验证交互。
- 让视觉改动与数据获取、权限判断和网络请求逻辑保持解耦。

**Non-Goals:**

- 不修改 API、路由、请求/响应结构、身份会话、CSRF、班级隔离或角色权限。
- 不增加搜索、筛选、删除、预览、批量上传等新功能。
- 不引入 CSS 框架、图标包、字体服务或新的构建依赖。
- 不翻译后端返回的动态错误消息，也不改变材料元数据内容。

## Decisions

### D1: 使用 CSS 自定义属性集中定义红色主题

在 `:root` 定义主红、深红、浅红背景、文字、边框、阴影和焦点环等设计令牌，组件样式只引用令牌。主操作使用高对比度实心红色，次要操作使用白底红边，页面背景和卡片使用暖白与浅红层次。

选择该方案是因为项目当前只有一份原生 CSS，令牌可在最小改动下消除散落色值，并统一 hover、active、focus-visible、disabled 状态。未选择 Tailwind、CSS-in-JS 或组件库，因为它们会引入与本次纯视觉改版不相称的依赖和迁移成本。

### D2: 保留组件数据流，只调整呈现结构与静态文案

`AuthProvider`、网络请求、角色判断、导航目标和表单提交函数保持不变；仅调整 JSX 的语义分组、装饰元素、类名和可见操作文案。登录页采用带品牌说明和表单卡片的双区布局，材料页保留标题区、操作区和卡片网格，上传页保留单表单流程并强化说明层级。

选择增量调整而非重写组件，可将回归风险限制在呈现层并确保“不修改后端功能”的边界可审查。

### D3: 操作文案与进行中状态使用明确中文

操作映射固定为：`Sign in` → `登录`、`Signing in…` → `登录中…`、`Refresh` → `刷新`、`Refreshing…` → `刷新中…`、`Upload material` → `上传资料`、`Uploading…` → `上传中…`、`Download file` → `下载文件`、`Back to materials` → `返回资料库`、`Log out` → `退出登录`。相关测试按这些可见名称定位控件。

保留账号、文件名、MIME 类型和后端错误等动态内容原样，避免前端猜测或重写后端语义。

### D4: 用现有测试验证行为，用样式检查验证主题与响应式基础

更新 Vitest 和 Playwright 中依赖英文控件名称的定位器，同时保留原有登录、退出、角色可见性、上传和下载断言。补充前端测试检查关键中文操作存在，并通过构建、lint、typecheck 和现有端到端流程防止呈现改动破坏行为。

不采用截图像素基线作为必需门槛，因为仓库当前没有稳定的视觉回归基础设施，跨平台字体渲染会制造噪声；实现阶段改用浏览器实看与关键布局/控件断言确认视觉结果。

## Risks / Trade-offs

- [红色使用过多会造成警示感或降低层级] → 仅主操作和重点状态使用实心红，内容区域以中性色和浅红强调为主。
- [中文文案长度改变可能导致窄屏溢出] → 操作组允许换行，窄屏下页头和操作区纵向排列，并避免固定控件宽度。
- [只更新文案会导致测试定位失效] → 同步更新 Vitest 与 Playwright 的角色名称定位器，并运行完整前端质量命令。
- [视觉改动意外触碰业务逻辑] → 将改动限定在 JSX 呈现、CSS 和测试文案，不改 fetch URL、方法、请求头、负载、角色分支或导航路径。

## Migration Plan

1. 先更新主题令牌与基础组件状态，再调整三个页面的呈现结构和中文操作文案。
2. 同步更新单元测试及 Playwright 控件定位文案。
3. 运行前端 lint、typecheck、Vitest、生产构建与可用环境下的 Playwright 测试。
4. 发布沿用现有前端镜像和路由，无数据迁移与后端部署变更。
5. 如需回滚，仅回退前端呈现、样式和对应测试文件；后端与数据无需处理。
