## Why

CampusClaw 目前只能按班级浏览和下载资料，用户无法从持续增长的 PDF、纯文本和 Markdown 资料中直接获得有依据的答案。新增严格受班级边界保护的单轮 RAG（Retrieval-Augmented Generation）问答，可以让教师和学生用自然语言提问，由 LLM 仅依据本班资料作答并提供可核验引用，同时避免模型常识、提示注入或跨班级内容成为信息泄露通道。

## What Changes

- 为已完成入库的 PDF、纯文本和 Markdown 资料抽取文本、分块并建立关键词与向量索引；不支持的格式仍可存储和下载，但明确显示为不可检索。
- 提供教师和学生均可使用的班级内单轮知识库问答 API：先执行关键词、向量或混合检索，默认使用混合检索及 Reciprocal Rank Fusion（RRF），再把通过服务端授权复核的有界证据交给 LLM。
- 生成式 LLM 仅能基于本次检索到的本班证据回答；回答中的事实性陈述必须引用有效来源编号，来源卡片包含资料标识、标题、原始文件名、页码或文本行范围、摘录及现有授权入口。
- 当本班没有足够证据时，统一返回 `根据本班资料无法回答该问题`，不得用模型预训练知识、其他班级内容或未经引用的推测补全答案。
- 所有索引、召回、证据组装、生成和来源解析均仅从服务端登录会话读取 `class_id`；客户端提供的任何班级编号都不能影响范围，LLM 也不参与班级选择或授权判断。
- 将问题和资料正文视为不可信数据。资料中的提示、角色声明或“忽略规则”等内容不能覆盖系统指令、请求额外数据、改变检索范围或泄露配置；输出必须经过结构、引用和来源授权校验后才能返回。
- 在现有资料库页面增加独立的“知识库问答”区域，采用单轮问题—答案交互，显示回答、引用、检索/降级状态以及索引状态；不保存或自动携带历史对话，不引入多轮聊天或自主 Agent。
- 使用服务端配置的 OpenAI-compatible 嵌入与生成接口；端点可位于校内私有网络或经批准的外部服务。密钥、模型、数据边界、超时和上下文限制仅存在于后端配置中，外部传输必须显式获批并受到最小化、脱敏和失败保护。
- 在 PostgreSQL 的 `knowledge_chunks` 保存切片正文、来源和关键词检索数据，在 Qdrant 中仅保存浮点向量和必要标识；Qdrant point 主键与 `knowledge_chunks.id` 完全相同，向量召回后必须回 PostgreSQL 取回并复核证据。
- 更新 PostgreSQL/Alembic 迁移、Qdrant collection、内部索引 worker、Compose、备份恢复、健康检查和运维文档，使检索索引、LLM 配置及降级状态纳入可部署、可恢复、可诊断的系统边界。
- 修改 README 和运维文档时移除与本变更冲突的“材料检索、问答、生成式 AI”非目标，但继续明确不实现多轮智能对话、自主工具调用、作业提交、学情诊断、教案/命题、注册、找回密码、技能开关、MCP、多智能体和知识图谱。

## Capabilities

### New Capabilities

- `materials/knowledge-retrieval`: 定义班级范围内的资料索引、混合检索、单轮 RAG 回答、可验证引用、无证据拒答、提示注入防护、模型数据边界、故障降级及前端问答行为。

### Modified Capabilities

- 无。当前主规格目录尚未包含已归档能力；本变更在新能力中完整规定知识库问答专属的班级隔离行为，并复用现有材料访问授权边界。

## Impact

- **后端与 API**：FastAPI 路由、应用服务、资料入库后的索引流程、文本抽取器、嵌入客户端、混合排序、生成式 LLM 客户端、证据包构造、结构化输出与引用校验，以及单轮问答响应模型。
- **数据层**：PostgreSQL 增加可检索资料状态、`knowledge_chunks` 切片正文和关键词索引；Qdrant collection 仅保存浮点向量及 `chunk_id`、班级、资料、索引版本等必要标识，不保存切片文本。
- **前端**：React 资料库增加“知识库问答”区域、问题输入、带引用回答、来源卡片、无证据拒答、生成/检索降级、索引处理中和失败状态，不增加多轮会话页面。
- **依赖与配置**：新增 PDF 文本抽取、Qdrant、OpenAI-compatible 嵌入与生成客户端依赖；新增仅服务端可见的端点、密钥、数据边界、模型、维度、温度、超时、批量大小和上下文预算配置。
- **安全与隐私**：新增问题及证据外发审批、提示注入隔离、输出与引用验证、日志脱敏和模型不可参与授权的约束。
- **部署与运维**：增加内部 Qdrant 与索引 worker，更新 Compose、健康检查、迁移、双存储备份恢复、容量规划及敏感内容外发说明；嵌入或向量服务不可用时可按规则降级检索，生成服务不可用时不得伪造回答。
- **兼容性**：现有登录、班级材料列表、上传、元数据和下载 API 保持兼容；已存在的受支持资料需通过受控回填任务建立索引。
- **文档范围**：README 与 `docs/operations.md` 需说明本变更实现单轮、引用约束的 RAG 问答，并继续明确不包含多轮聊天、自主 Agent、作业、学情、备课、命题、技能/MCP、多智能体或知识图谱。
