## Why

CampusClaw 目前只能按班级浏览和下载资料，用户无法在持续增长的 PDF、纯文本和 Markdown 资料中快速定位相关内容。新增受服务端班级边界保护、且每条结果可追溯到原始资料的混合检索，可提高课程资料的可发现性，同时避免搜索成为跨班级信息泄露通道。

## What Changes

- 为已完成入库的 PDF、纯文本和 Markdown 资料抽取文本、分块并建立关键词与向量索引；不支持的文件格式仍可正常存储和下载，但明确显示为不可检索。
- 提供面向教师和学生的班级内混合检索 API，将关键词召回与语义向量召回合并、排序，并支持有界查询和分页/结果数量限制。
- 所有索引、召回和来源解析均由服务端从已认证用户的 `class_id` 派生作用域，不接受客户端选择其他班级，也不泄露其他班级资料或分块是否存在。
- 每个搜索结果返回可验证的来源卡片，包括资料标识、资料标题、原始文件名、页码或文本行范围、可选章节标签、命中摘录及相关性信息，并可跳转到现有资料详情或下载入口。
- 检索 API 只返回命中数量、检索模式和来源证据，不生成答案、解题步骤、总结或教学建议；无命中时明确返回本班暂无相关资料，不以其他班级内容或模型常识补全。
- 在现有资料库页面增加独立的“讲义与检索”区域，覆盖加载、空结果、无命中引导、不可检索资料、索引处理中和索引失败等状态，不引入聊天式问答界面。
- 使用服务端配置的 OpenAI-compatible 嵌入 API 生成向量；端点可以位于校内私有网络或经批准的外部服务，密钥、数据边界模式和端点仅存在于后端配置中，并定义显式外发授权、超时、失败降级、重试和模型/维度兼容性约束。
- 更新数据库迁移、Compose 配置、备份恢复、健康检查和运维文档，使检索索引及其配置纳入可部署、可恢复和可诊断的系统边界。
- 修改 README 和运维文档时仅移除与本变更冲突的“材料检索、全文检索、向量检索”非目标；继续明确不实现问答、RAG 生成、智能对话、作业提交、学情诊断、教案/命题、注册、找回密码、技能开关、MCP、多智能体和知识图谱。

## Capabilities

### New Capabilities

- `materials/knowledge-retrieval`: 定义班级范围内的资料索引、混合检索、来源溯源、索引状态、故障降级及前端检索行为。

### Modified Capabilities

- 无。当前主规格目录尚未包含已归档能力；本变更在新能力中完整规定检索专属的班级隔离行为，并复用现有材料访问授权边界。

## Impact

- **后端与 API**：FastAPI 路由、应用服务、资料入库后的索引流程、文本抽取器、服务端嵌入客户端、混合排序，以及只包含检索证据而不包含生成答案的来源响应模型。
- **数据层**：PostgreSQL/Alembic 增加可检索资料状态、文本分块、全文索引和向量列；数据库镜像需提供选定的向量扩展。
- **前端**：React 资料库增加“讲义与检索”区域、搜索输入、来源卡片、无命中引导、来源定位、索引状态和错误/降级提示，不增加问答页面。
- **依赖与配置**：新增 PDF 文本抽取、向量扩展及嵌入 API 客户端依赖；新增仅服务端可见的端点、密钥、数据边界模式、模型、维度、超时和批量大小配置。
- **部署与运维**：更新 Compose、健康检查、迁移、备份恢复、容量规划及敏感内容外发说明；支持校内私有嵌入端点，经批准的外部端点必须显式启用外发，嵌入服务不可用时关键词检索仍可用。
- **兼容性**：现有登录、班级材料列表、上传、元数据和下载 API 保持兼容；已存在的可支持格式资料需通过受控回填任务建立索引。
- **文档范围**：README 与 `docs/operations.md` 只移除与检索能力冲突的非目标声明，并继续明确不包含问答、生成式 AI、作业、学情、备课、命题、技能/MCP、多智能体或知识图谱。
